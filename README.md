# BrainAI —— 非 transformer 的多模态小模型（树莓派 CPU 训练）

## 设计

```
视频 (B,T=16,1,64,64) → 3D 卷积堆栈（空间 64→8，时间 16→4）→ z_v (128)
音频 (B,1,40,64)      → 2D 卷积堆栈（梅尔谱）                → z_a (128)
文本 (B,L=16)         → 字符 Embedding + 膨胀卷积(1/2/4/8)    → z_t (128)
融合                   → 三路 FiLM 门控（互相调制）+ 拼接 MLP  → z_j (128)
输出                   → ① 重建 16 帧@32×32  ② 逐位置字符预测
损失                   → 重建 MSE + 字符 CE + 三对 InfoNCE（v-t / a-t / v-a）
```

- **没有 transformer**：没有 token 序列的位置编码，没有自注意力
- **顺序性**靠因果膨胀卷积（感受野覆盖整个片段）
- **压缩**靠 3D 卷积逐层降采样 + 池化（模拟"忽略不重要部分、合并静止片段"）
- 参数量约 2.1M，树莓派 4 核 CPU 上 0.5–0.9 秒/步（batch 4–8）

## 文件

| 文件 | 作用 |
|---|---|
| `model.py` | 模型定义 |
| `data_synth.py` | 合成数据（移动几何体 + 自动描述），验证架构 |
| `data_video.py` | 从媒体库抽片段+字幕（ffmpeg 稀疏取帧） |
| `train.py` | 训练（`--data synth|real`，断点续训） |
| `eval.py` | 跨模态检索准确率 |

## 用法

```bash
python3 data_video.py --files 12 --clips 25     # 抽真实数据
python3 train.py --data real --steps 3000       # 训练（自动续训）
python3 eval.py --n 32                          # 评测检索准确率
```

## 已知结果（2026-11-07）

- 合成数据 780 步：重建 MSE 0.046、字符预测 CE 0.002、**跨模态检索 65.6%**（32 选 1，随机 3.1%）
